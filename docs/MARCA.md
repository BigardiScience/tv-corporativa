# Identidade visual e ativos

A interface usa uma identidade neutra, pensada para qualquer empresa. Todos os ativos abaixo foram criados para este projeto e podem ser trocados pela marca de quem for usar a plataforma.

| Recurso local | O que é |
| --- | --- |
| `public/assets/logo.png` | Símbolo genérico de uma tela com o ícone de reprodução, 163 × 98 pixels, fundo transparente |
| `public/assets/destaque.jpg` | Ilustração abstrata de telas exibindo comunicados, 600 × 400 pixels |
| `public/assets/favicon.svg` | Ícone da aba do navegador, com o mesmo símbolo de tela |

A cor de destaque é o laranja `#F97219`. Cores de texto e botões podem usar tons mais escuros para leitura e contraste.

A referência funcional foi a [OptiSigns](https://www.optisigns.com/), pela organização de conteúdo, telas e programação. O projeto não usa seu código ou sua identidade visual.

As unidades iniciais de exemplo são Unidade Centro, Unidade Leste, Vila Norte e Unidade Oeste. Os setores iniciais são RH, TI, SEGURANÇA DO TRABALHO e TESTE. Ajuste os nomes, os responsáveis e o escopo antes de habilitar contas reais.

Para usar a marca de uma empresa, substitua `public/assets/logo.png` e `public/assets/destaque.jpg` por arquivos com os mesmos nomes e dimensões.
